# Narration prompt

Write a 35–50 second voiceover about the actual PR. Aim for 95–120 plain words.

Tone: dry-fun and specific. State the actual UI changes in page order, matching the demo beats. Include each beat cue verbatim, exactly once. Do not invent atmosphere that is not in the PR. Avoid SEO unless it is visibly demonstrated, hype, piles of internet slang, emoji, or generic compliments. The narration should make sense without seeing the diff, then end cleanly without a call to subscribe. Captions render at the bottom over gameplay; active words are red.
