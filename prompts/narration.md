# Narration prompt

Write a 45–60 second voiceover about the actual PR. Aim for 110–140 plain words.

Read `artifacts/pr-brief.txt` and the live UI. Write the take from those, not from the title alone. Do not narrate file paths. Do not invent UI that is not in the brief or the preview.

Tone: dry-fun and specific. Two acts. First state the review take: what the PR actually did and why it matters. Then narrate while the demo checks the live UI. Do not walk the DOM heading by heading.

Include each beat cue verbatim, exactly once. Cues do not need to cover every heading; only the inspect beats. Do not invent atmosphere that is not in the PR. Avoid SEO unless it is visibly demonstrated, hype, piles of internet slang, emoji, or generic compliments. End cleanly without a call to subscribe. Captions render as phrase blocks over gameplay, not word karaoke.
